Aplicativo Controle de Gastos

Este é um aplicativo mobile desenvolvido em React Native para realizar o cadastro, listagem, edição, exclusão e armazenamento local de gastos pessoais. O projeto foi construído para atender aos requisitos da avaliação prática, demonstrando o uso de componentes funcionais, gerenciamento de estado e navegação.

Vitor Luiz Soares da Silva

Dependências
O projeto foi desenvolvido utilizando as seguintes tecnologias e bibliotecas:
*React Native* e *Expo* (Framework e ambiente de desenvolvimento)
*React Navigation* (`@react-navigation/native`, `@react-navigation/native-stack`) para o roteamento entre as telas
*Expo SQLite* (`expo-sqlite`) para a persistência de dados localmente no dispositivo 
*Expo Vector Icons* (`@expo/vector-icons`) para a iconografia da interface

Instruções de Execução

Para testar o aplicativo na sua máquina, siga os passos abaixo:

1. *Clone o repositório:*
   git clone [https://github.com/VitorSoaresGoad/Avalia-oP2.git](https://github.com/VitorSoaresGoad/Avalia-oP2.git)

2. Acesse a pasta do projeto (caso os arquivos estejam dentro de uma subpasta):
   cd Avali-oP2

3. Instale as dependências:
   npm install

4. Inicie a aplicação:
   npx expo start

5. Testando o App:
Instale o aplicativo Expo Go no seu smartphone.

Certifique-se de que o computador e o celular estão na mesma rede Wi-Fi.

Escaneie o QR Code gerado no terminal usando o aplicativo do Expo Go (ou a câmera do celular, se for iOS).
